## 维护约定

- 文档内的相对链接一律相对**本目录**（或文档所在子目录）书写，移动文件后请同步修正链接。
- 中间过程产物（探针脚本的 before/after 快照、harness、运行日志、生成的大体积 diff）**不入库**；只把结论性报告归档到本目录。
- 报告类文档若被后续报告取代，请在被取代文档顶部加一行指向新文档的说明，不要直接删除。
